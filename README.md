# led_acender

Aluno: Lucas Silva Amaral

Controlar o LED com botão

Cada vez que apertar o botão o LED acende 

Materiais necessários
Qtd.	Componente
1	Placa Arduino UNO
1	Cabo USB
1	Protoboard
2	Resistores de 220 Ω
1	Resistor de 10 kΩ
1	Botão tipo push button
2	LEDs vermelhos difusos de 5 mm
—	Fios de jumper macho-macho
